# AI Memory & Local Rules — Vibe Portfolio

## Архитектурный контекст
Проект `vibe_portfolio` представляет собой клиентское Web-приложение портфолио, разворачиваемое на GitHub Pages.

## Правила для ИИ-агентов
1. **Исходный код верстки**: `src/sections/*.html` + `src/template.html`.
2. **Запрет прямого изменения**: Не вносить изменения вручную в `index.html`. Всегда использовать `npm run build` (`node build.js`).
3. **Правила CSS**: Стили находятся в `css/`. Главный файл импорта — `index.css`. Единственный файл медиазапросов — `css/responsive.css`. `css/responsive-v9999.css` был удален и не должен создаваться заново.
4. **Git Изоляция**: Пуш выполнять строго в `origin main` репозитория `vibe_portfolio` (`git@github.com:kizune-ne/vibe_portfolio.git`).
5. **Версионирование**: `build.js` генерирует версионную плашку вверху сайта с хэшем Git-коммита.
